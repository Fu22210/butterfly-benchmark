# От принятого ответа до эталона

| Файл | Содержимое |
|---|---|
| [final_accepted.json](final_accepted.json) | 400 принятых записей. Содержат рамки, вердикт и доступные в выгрузке связи с предыдущими проверками. |
| [adjudication.jsonl](adjudication.jsonl) | Пять дополнительных разборов с пояснениями. Поля original_boxes и final_boxes позволяют восстановить изменение. |
| [gold.jsonl](../model_comparison/gold.jsonl) | Итоговые рамки по всем 400 ID для оценки моделей. |

В публичной копии идентификаторы исполнителей, проверяющих, заданий и проверок заменены псевдонимами. Один участник имеет один псевдоним в обеих ролях. Из вложенных записей исключены свободные комментарии и служебные сведения. ID фотографий, координаты и вердикты сохранены.

Для фото 353285 дополнительный пересмотр изменил рамку. Для 97982, 386237, 1456817 и 2443321 принятое выделение сохранено. Поле method указывает на визуальный разбор с помощью модели. Описание последовательности независимого ревью приведено в слайдах защиты. Полная история выгрузок по раундам доступна в этой публикации лишь в объёме полей принятых записей.
