# Сравнение моделей на 400 фотографиях команды

Входы лежат в `../butterfly_dataset/main/images`. Список и контрольные суммы фотографий приведены в `../butterfly_dataset/main/metadata.jsonl`. В `gold.jsonl` сохранена версия эталона с SHA-256 `3d24db4441094a99a21e49b74e2a5c94c0e00bb6632989bb45e4b577f08d974b`. В ней 193 объекта и 209 пустых кадров. Инференс читает только исходные изображения, а числовое имя файла связывает результат с идентификатором фотографии.

## Запуск

Рабочая директория — папка этого README. Окружение исходного запуска использует Python 3.12.13 и NVIDIA A100 PCIe 80 GB, PyTorch и torchvision собраны с CUDA 13.0. Файл requirements.txt фиксирует версии библиотек. Точные ревизии весов и полные запросы приведены в infer.py.

```sh
python -m pip install -r requirements.txt
export CUDA_VISIBLE_DEVICES=2
export OMP_NUM_THREADS=2
for model in dino owl qwen
do
  python infer.py "$model" ../butterfly_dataset/main/images predictions
done
python evaluate.py gold.jsonl predictions --metadata ../butterfly_dataset/main/metadata.jsonl
```

Подставьте доступную GPU. При первом запуске требуется доступ к Hugging Face для загрузки весов. Каждый новый набор настроек запускайте в отдельном каталоге результатов. Повтор той же команды с теми же настройками продолжает вычисление по журналу.

## Конфигурации

Все три модели получают полный RGB-кадр после применения EXIF-ориентации. Изменение размера и нормализацию выполняет процессор из соответствующей ревизии. Пакет содержит одно фото.

| Модель | Настройки |
|---|---|
| Grounding DINO tiny | FP32, запрос `butterfly. moth.`, порог рамки 0,30, порог текста 0,25 |
| OWLv2 base patch16 | FP32, два запроса `a photo of a butterfly` и `a photo of a moth`, порог 0,10 |
| Qwen3-VL-2B-Instruct | BF16, SDPA, жадная генерация до 512 новых токенов, запрошенный диапазон визуального процессора 65 536–1 048 576 пикселей, координаты ответа 0–1000 |

Для детекторов рамки обрезаются по границам кадра, вырожденные рамки отбрасываются, пересекающиеся с IoU выше 0,50 подавляются посредством class-agnostic NMS. Для Qwen разбирается JSON из ответа, координаты делятся на 1000 и ограничиваются границами кадра. Все модели сохраняют `left, top, width, height`.

## Оценка

Для каждого кадра evaluate.py находит максимальное по числу пар двудольное сопоставление при заданном IoU. Суммы TP, FP и FN по кадрам определяют общие precision, recall и object F1. При порогах 0,50 и 0,75 сопоставление выполняется заново. Число фоновых FP считает лишние рамки на пустых кадрах. Показатель empty_with_fp считает пустые кадры хотя бы с одной лишней рамкой. При нулевом знаменателе значение метрики в JSON равно нулю.

В predictions/*.jsonl лежат предсказания и журналы по кадрам. Время включает чтение изображения, преобразование, инференс и постобработку с синхронизацией CUDA. Загрузка весов не входит. Группы из metadata.jsonl используются только при подсчёте итогов. Экзаменационные фотографии для этих прогонов не используются.

## Подтверждение рамок двумя моделями

Qwen предлагает рамки. Для каждого кадра стратегия оставляет предложения Qwen, которые пересекаются с уверенными детекциями OWLv2. Пары рассматриваются по убыванию IoU, каждая рамка подтверждает максимум один объект. Выходные координаты берутся из Qwen. На командном наборе выбраны порог OWLv2 0,40 и минимальный IoU между моделями 0,30. Порог оценки по эталону остаётся 0,50.

Для воспроизведения подбора по сохранённым прогонам выполните:

```sh
python strategy.py tune gold.jsonl predictions strategy_results
```

Поиск сравнивает 43 конфигурации, включая три базовых варианта. Критерий выбора — общий F1@0,5. При равенстве приоритет получает конфигурация с меньшим суммарным временем инференса. Для дополнительной проверки скрипт перемешивает ID с фиксированным seed, делит 400 кадров на пять частей, выбирает правило на 320 кадрах и применяет его к остальным 80. Отложенные предсказания всех пяти частей объединяются перед вычислением F1. Подробные результаты для каждого варианта и разбиения лежат в `strategy_results/evaluation.json`.

Для новых фотографий с числовыми именами нужен отдельный пустой каталог результатов. Команды ниже используют параметры победителя из `strategy_results/config.json`. Эталон этому запуску не нужен.

```sh
python infer.py owl /path/to/new/images new_predictions
python infer.py qwen /path/to/new/images new_predictions
python strategy.py apply strategy_results/config.json new_predictions new_predictions/answer.jsonl
```

На полном командном наборе выбранный ансамбль получил F1@0,5 0,9337 и F1@0,75 0,8520. Все пять разбиений выбрали одно правило. Среди конфигураций с единственной моделью лучший F1@0,5 у OWLv2 с порогом 0,40 (0,8878).
