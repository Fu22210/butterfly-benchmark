## Происхождение и контроль

Отбор выполнен через iNaturalist `GET /v1/observations` с фильтром `photo_license=cc0`. Для 600 оригиналов подтверждено значение `cc0` у конкретного photo ID в ответе v1. Затем каждый ID подтверждён повторным запросом подробностей наблюдения через API v2 без фильтра по лицензии. Ссылки на запросы, время и результаты проверок есть в обоих манифестах.

Все 600 локальных оригиналов декодируются. Фотографии основного набора и резерва сверены по ID, SHA-256 и перцептивным хешам.

Поле `photo_attribution` передаёт сведения iNaturalist о правах и авторстве. Когда iNaturalist передаёт только «no rights reserved», для происхождения сохранены профиль наблюдателя и имя автора из EXIF, если оно присутствует.
