ВЫБОРКА ДЛЯ ПИЛОТА: 400 + 100 ФОТОГРАФИЙ

Это предложенная выборка для дальнейшей разметки, а не golden set.
Она не содержит предсказаний моделей или проверенных эталонных рамок.
Признаки группы и стадии развития взяты из публичных наблюдений iNaturalist.
Они относятся к наблюдению и не гарантируют содержимое каждой его фотографии.
Растения и другие насекомые могут оказаться на одном кадре со взрослой бабочкой.

БЫСТРЫЙ СТАРТ
Откройте gallery.html в браузере — установка или сервер не нужны.
Фильтры позволяют выбрать часть набора и группу организмов.
Клик по изображению открывает скачанный оригинал.
Все списки фото находятся в manifests/, изображения — в images/.
visual_review_notes.json содержит заметки агента по сложным примерам после
просмотра миниатюр всех 500 фото. Они показаны в галерее и не являются
независимой человеческой проверкой, эталонными ответами или разметкой рамок.

ЧАСТИ НАБОРА НЕ ПЕРЕСЕКАЮТСЯ
main400       — bbox → независимое review → исправления → оценивание моделей.
training30    — банк примеров для инструкции и обучения исполнителей.
bbox_exam20   — банк экзаменационных примеров для допуска к bbox.
review_exam20 — банк экзаменационных примеров для допуска к review.
control30     — отдельный банк контрольных заданий для контроля качества.

100 — размер банка, а не обязательное число заданий на одного исполнителя.
Конкретная длина экзамена и частота контроля выбираются отдельно с учётом 850 ₽.
Никакие платные задания этим скриптом не создаются.
Порог допуска и зарплата исполнителей ещё не настроены.

ДО ЗАПУСКА ЯНДЕКС ЗАДАНИЙ
1. Просмотрите галерею; подтвердите, что выбранные фотографии подходят задаче.
2. Уточните у преподавателя противоречие про ночных бабочек / молей:
   обновлённое описание включает ночных бабочек, текст Контеста исключает молей.
   Здесь 40 ночных фото включены в основной набор по обновлённому описанию.
3. Для дополнительных 100 фото подготовьте и независимо проверьте эталонные рамки.
   Файлы *_gold_PENDING.jsonl содержат boxes=null: это явные незаполненные записи.
   Не считайте их готовыми ответами и не загружайте как эталоны в платформу.
4. Для экзамена review подготовьте варианты предложенной разметки:
   верные рамки, пропущенный объект, лишнее выделение, неточные границы.
   Каждый вариант должен иметь заранее проверенный вердикт.
5. Зафиксируйте основной список, после этого организуйте bbox и отдельный review.
   Автор исходной разметки не должен проверять её сам.

ИСТОЧНИК И ОТБОР
Источник: публичный API iNaturalist, компактный /v2/observations.
Он возвращает те же публичные наблюдения, что и /v1/observations из задания;
fields ограничивает размер ответа нужными полями. API-ключ не требуется.
Для каждой фотографии отдельно проверено photo.license_code == cc0.
Сохранены автор, ID фото и наблюдения, ссылки, таксон, аннотации стадии развития.
Поле author содержит имя пользователя исходного наблюдения; исходная строка
атрибуции фотографии сохранена отдельно в attribution. Эти поля не являются
независимой проверкой личности фотографа.
Сведения о лицензиях отражают состояние источника при сборе, оно может измениться.
Оригиналы скачаны из публичного S3 iNaturalist; их байты не изменялись.

Взяты кандидаты из четырёх временных окон создания наблюдений:
с марта 2020, июня 2021, сентября 2023 и января 2025 до конца соответствующего года.
Это разнообразная учебная выборка, а не случайная репрезентативная выборка всей природы.
Дата загрузки и дата наблюдения могут отличаться.
Дополнительные ограничения: один кадр на наблюдение, не более 12 фото автора
и не более 6 фото одного таксона во всём наборе 500.
Для взрослых насекомых и незрелых стадий использованы аннотации Life Stage.
Плановые квоты, параметры запросов и seed сохранены в sampling_config.json.
Кеш исходных ответов API: cache/. Полный резерв кандидатов: candidates.jsonl.

ИСКЛЮЧЕНИЕ ЭКЗАМЕНА И ДУБЛИКАТОВ
Все 400 экзаменационных photo_id исключены явно.
Также исключены известные ID исходных наблюдений для 350 экзаменационных фото.
Для оставшихся 50 наблюдения ранее не удалось восстановить; для всех 400 фото
используются визуальные отпечатки миниатюр.
SHA-256 исключает точные дубликаты выбранных файлов.
dHash с расстоянием <= 3 исключает похожие кадры внутри 500 и относительно экзамена.
Это эвристика: она не гарантирует обнаружение любых обрезок и изменений изображения.
Решения об отклонении и ошибки загрузки записаны в rejections.jsonl.
Кадры с нестандартным EXIF-поворотом исключены, чтобы избежать неоднозначности координат.

ДЛЯ МОДЕЛЕЙ
Используйте main400_images_only.jsonl и изображения.
Не передавайте модели taxon_name, source_group, annotations и прочие метаданные.
Все три модели оцениваются на одинаковых основных 400 фото после завершения golden set.
Дополнительные 100 предназначены для контроля разметчиков и не входят в лидерборд.
Эта выборка не используется для обучения весов моделей.

ВОСПРОИЗВОДИМОСТЬ
Нужны Python 3.10+ и Pillow (см. requirements.txt).
python3 collect.py fetch
python3 collect.py select
python3 collect.py validate

fetch сохраняет ответы API; select повторяет отбор с фиксированным seed и кешем.
Живой iNaturalist меняется. Для точного повторения сохраняйте исходный cache/,
candidates.jsonl, манифесты, reference/ и SHA-256 оригиналов.
После ручных замен манифесты и проверки необходимо обновить вместе.
validation.json содержит фактический состав и результаты структурных проверок.

ОГРАНИЧЕНИЯ
Распределение по группам задано специально для учебного сравнения.
Покрытие нескольких объектов, сильных перекрытий и очень мелких бабочек
не гарантируется аннотациями API: эти сценарии нужно проверить по фотографиям.
Отбор по доступной аннотации стадии развития может смещать выборку к более
понятным и активно проверенным наблюдениям.
